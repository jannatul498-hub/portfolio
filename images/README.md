# Images Folder — Jannatul Ferdaus Portfolio

Place your images here with these exact filenames:

## Profile Photo
- `profile.jpg` — Your profile/personal photo (used in Home & About pages)

## Project Images
- `project-dementia.jpg`  — Photo of your Dementia Patient Assistive Device (2nd semester project)
- `project-garden1.jpg`   — Balcony garden / main gardening photo
- `project-garden2.jpg`   — Kitchen herb garden photo
- `project-photo1.jpg`    — Botanical / flower photography sample
- `project-photo2.jpg`    — Campus life / RUET photography sample
- `project-robot2.jpg`    — Line following robot photo (optional)

## Tips
- Recommended size: 800x600px minimum for project images
- Profile photo: square crop works best (e.g., 500x500px or 600x800px portrait)
- Format: JPG or PNG
- If a photo is missing, the website will display a friendly placeholder automatically

All image fallbacks are handled gracefully in the HTML using the onerror attribute.
