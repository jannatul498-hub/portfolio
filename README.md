## ⚡ JavaScript Features

1. **Form Validation** — Real-time + on-submit validation (required fields, email format, minimum message length)
2. **Typing Effect** — Animated role text on home hero
3. **Dark/Light Theme Toggle** — Persisted via localStorage
4. **Skill Bar Animation** — Progress bars animate on scroll into view
5. **Scroll Reveal** — Cards and sections fade in as you scroll
6. **Animated Counters** — Numbers count up when visible
7. **Project Filter Buttons** — Filter by category (All, Robotics, Gardening, Photography)
8. **Mobile Hamburger Menu** — Smooth open/close with CSS animation
9. **Sticky Nav** — Changes appearance on scroll
10. **Back to Top Button** — Appears after scrolling 400px

## 🎨 Design

- **Color Scheme:** Soft bluish palette (CSS variables)
- **Fonts:** Playfair Display (headings) + DM Sans (body) + Fira Code (mono)
- **Responsive:** Works on desktop, tablet, and mobile
- **No inline styles** (except minor necessary overrides)
- **External CSS only** — single `style.css` file

## 🚀 Hosting on Netlify (Free)

1. Go to [netlify.com](https://netlify.com) and sign up
2. Click **"Add new site" → "Deploy manually"**
3. Drag and drop the `portfolio/` folder into the upload zone
4. Your site goes live at a URL like `https://jannatulferdaus.netlify.app`
5. (Optional) Rename the site in Site Settings
